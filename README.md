# Exam

## Резюме проекта

В этом проекте научилась применять ООП/процедурный/мультипарадигмальный подход в Python, а также написала код, придерживаясь функциональной парадигмы.

---

## Описание задачи

Студенты пришли сдавать экзамен. Его принимают одновременно несколько экзаменаторов. Студенты сидят в одной общей очереди. Как только кто-то из экзаменаторов освобождается, к нему сразу заходит первый студент из очереди.

Спустя 30 секунд после начала экзамена экзаменатор имеет право на обед, поэтому заканчивает работу с текущим студентом и в течение случайного времени в интервале от 12 до 18 секунд после этого никого не принимает.

---

## Процесс сдачи экзамена

Сдача экзамена происходит следующим образом:

- Студенту по очереди задаются три вопроса из банка вопросов.
- Студент в качестве ответа выбирает наугад любое слово из вопроса.
- По статистике мальчики вероятнее выбирают слова ближе к началу вопроса, а девочки — ближе к концу. Вероятности распределяются по закону золотого сечения (Ф ≈ 1.618...).
  
  **Пример:**
  - Вопрос: «Там стоит стол»
  - Мальчик:
    - «Там» с вероятностью a = 1/Ф
    - «стоит» с вероятностью b = (1 - a)/Ф
    - «стол» с вероятностью c = 1 - a - b
  - Девочка (наоборот):
    - «стол» с вероятностью a
    - «стоит» с вероятностью b
    - «Там» с вероятностью c

Экзаменатор заранее не знает ответ на свой вопрос, поэтому поступает аналогично, выбирая наугад слова. Верных ответов может быть несколько, так как экзаменатор с вероятностью 1/3 выбирает ещё одно слово и повторяет это, пока не остановится или не выберет все слова вопроса.

---

## Оценка результатов

Экзаменатор принимает решение, сдал студент экзамен или нет, исходя из своего настроения:

- Плохое настроение (вероятность 1/8) — студент не сдал.
- Хорошее настроение (вероятность 1/4) — студент сдал.
- Нейтральное настроение (вероятность 5/8) — объективная оценка (сдал, если верных ответов больше, чем неверных).

---

## Длительность экзамена

Время сдачи экзамена зависит от длины имени экзаменатора. Например, для имени «Степан» (6 символов) экзамен длится от 5 до 7 секунд (случайное вещественное число из диапазона).

---

## Реализация программы

При запуске программы:

- Из файла `examiners.txt` считывается список экзаменаторов.
- Из файла `students.txt` считывается список студентов, заранее пришедших и вставших в очередь.
- Из файла `questions.txt` считывается банк вопросов.

Каждый экзаменатор принимает экзамен в отдельном потоке.

---

## Вывод информации в консоли (во время экзамена)

В консоли должна актуализироваться информация:

- **Таблица студентов** (столбцы: «Студент», «Статус»):
  - Статусы: «Очередь», «Сдал», «Провалил».
  - Сортировка по статусу: сначала очередь, затем сдавшие, затем провалившие.

- **Таблица экзаменаторов** (столбцы: «Экзаменатор», «Текущий студент», «Всего студентов», «Завалил», «Время работы»):
  - Если экзаменатор обедает или закончил принимать, в столбце «Текущий студент» отображается «-».

- Отдельной строкой количество оставшихся в очереди студентов из общего числа.
- Отдельной строкой время с момента начала экзамена.

Информация должна синхронизироваться на месте, а не выводиться заново.

---

## Итоговый вывод после завершения экзамена

После завершения экзамена выводится итоговая информация:

- **Таблица студентов** (столбцы: «Студент», «Статус»):
  - Статусы: «Сдал», «Провалил».
  - Сортировка по статусу: сначала сдавшие, затем провалившие.

- **Таблица экзаменаторов** (столбцы: «Экзаменатор», «Всего студентов», «Завалил», «Время работы»).

Отдельными строками:

- Время с момента начала экзамена до его завершения.
- Имена лучших студентов (те, кто быстрее других сдали экзамен), через запятую.
- Имена лучших экзаменаторов (у кого ниже процент заваленных студентов), через запятую.
- Имена студентов, которых отчислят (провалившие экзамен раньше других проваливших), через запятую.
- Лучшие вопросы (на них верно ответило больше всего студентов), через запятую.
- Вывод о том, удался экзамен или нет (удался, если сдало более 85% студентов).
